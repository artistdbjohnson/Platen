PLATEN by DGLXSS

2017. A typewriter shop in West Los Angeles. My son was four, running the shop floor between dead ribbons and open cases while I paid for an Olympia SM3 with one intention. Write a novel no one would ever read. Private. Something to pass down to him one day.

The novel remains unfinished. And the typewriter has been following along ever since.

Then #plottertwitter. Artists feeding algorithms into machines, ink finding paper one mechanical decision at a time. Paul Prudence holding a pen against a platen roller, discovering he had a hand-operated plotter in his studio the whole time. Henri Chopin in 1985 mapping density through a split ribbon, blue and red, building form from the weight of repeated strikes. Ruth Wolf-Rehfeldt typing one word across an entire page until the word became a shape and the shape carried the meaning.

The SM3 in the corner looked different after that. A constraint system that had known how to translate a mathematical instruction into a physical mark since 1952.

PLATEN starts in mathematics. A closed-form calculation runs across every cell on a mechanical grid, geometric tests, sine-wave phase comparisons, lattice arithmetic. Each cell returns one number measuring how strongly that coordinate activates under the current pattern. No pixels, no image lookup, no rasterization anywhere in the chain. The number normalizes to a scalar between zero and one.

That scalar becomes a glyph. The glyph becomes a strike.

The full algorithm is open. The engine at the center is a switch across forty named patterns, each one computing weight analytically from pure geometry. Here is what that looks like in the code:

function calcMotifWeight(x, y, w, h, engine, params) {
    switch(engine) {
        case 'VERNA':
            // Perlin noise field sampled at rotated coordinates
            var nx = (x / w) * params.scale;
            var ny = (y / h) * params.scale;
            return Math.abs(noise(nx, ny, params.seed));

        case 'TNGNT':
            // Tangent wave interference pattern
            var fx = Math.tan(x * params.freq) * params.amp;
            var fy = Math.tan(y * params.freq) * params.amp;
            return Math.abs(Math.sin(fx + fy));

        case 'TOLM':
            // Distance field from lattice centers
            var gx = (x % params.cell) / params.cell;
            var gy = (y % params.cell) / params.cell;
            return 1.0 - Math.sqrt(gx * gx + gy * gy);

        // ... 37 further engines
    }
}

Every engine returns a raw float. That float gets normalized across the full grid, jittered deterministically by cell coordinate to prevent hard threshold edges, then mapped to a glyph:

// Pass 1: raw weight + deterministic jitter per cell coordinate
var jitter = baseWt > 0 ? (((cx * 37 + cy * 13) % 100) / 400.0) : 0;
rawWt.push(baseWt + jitter);

// Pass 2: normalize, ground to 0, discard bottom 7% as background
var wMin = 0;
var wRange = isFlat ? 1 : (wMax - wMin);
var norm = (rawWt[ri2++] - wMin) / wRange;
if (norm > 0.07) {
    grid[cx2][cy2].wt = norm;
}

// Scalar to glyph level — five bands
if      (cell.wt < 0.36) level = 0;   // comma
else if (cell.wt < 0.51) level = 1;   // dot
else if (cell.wt < 0.66) level = 2;   // plus
else if (cell.wt < 0.81) level = 3;   // x
else                     level = 4;   // asterisk

Dot. Comma. Plus. X. Asterisk. Slash. Hash. Dash. Eight possible outcomes per cell, each one natively typeable on a standard QWERTY SM3. The shift-key symbols, the punctuation, the letters, every mark in every output existed in the machine's mechanical vocabulary in 1952. The simulation never asks the SM3 to do something it could not physically do.

Forty engines. Each one a closed-form translation of a specific material culture, historical textile, or architectural system into pure scalar mathematics. The loom: kente, bogolan, adire, kuba, the stepped diamonds of Navajo tradition, the structured geometry of chiefs blankets and Serape optical tunneling. The compass: seigaiha concentric waves, asanoha hemp leaf lattices, kagome tri-axial basket weave, shippo overlapping circles, Islamic interlace strapwork built from multi-frequency radial math. The drafting table: tangents connecting nodes like architectural drawings, stolz recreating the Bauhaus grid after Gunta Stölzl, structural simulating blueprint hatching and nested frames. The machine turned against itself: glitch simulating data corruption, scanline tearing, bit-crushing, orak warping the grid into cosmic distortion.

All forty passing through the same bottleneck: the physical width of a type slug. 0.082 inches inside a 0.100-inch cell. 10 characters per inch, 6 lines per inch. The machine's actual specifications, inherited exactly.

Symmetry works the same way. Rotational, glide, translational operations don't mirror pixels after the fact. The coordinate space rotates before the noise samples, so the mathematics generates the symmetry natively. The typewriter destroys most of it. Eight glyphs hold what survives.

Print it, send it to a pen plotter. The output is raw SVG against real-world inches, laid over a scanned paper canvas at 600dpi, the texture of an actual sheet beneath every vector path. Screen is preview. The work only fully exists when pressed into a surface you can touch. Chopin made this argument with a ribbon. Prudence makes it with a platen roller. Wolf-Rehfeldt made it with one repeated word. The machine is not incidental. The machine is the point.

My son is thirteen now.

The novel is still unfinished. So is everything worth keeping.


Release Notes

PLATEN — 2026.05.31

Eight natively typeable glyphs mapped across five density levels: comma, dot, plus, X, asterisk, slash, hash, dash. Each character exists in the Olympia SM3's standard QWERTY vocabulary. The simulation inherits the machine's exact mechanical specifications — 10 CPI, 6 LPI, 0.082" type slug width — without approximation.

Glyph vocabulary is symmetry-aware. ROTAT outputs resolve through radially neutral characters. GLIDE outputs bias toward diagonal strikes. TRANS outputs carry horizontal weight. The character set reflects the underlying mathematical operation, not just the density it represents.

Forty generative engines. Deterministic ink variance per seed. Scanned paper canvas at 600dpi. Archival SVG output at real-world print dimensions.

88 editions. 0.088 ETH.
